# JUMP.LAB — CMJ MMPose backend

FastAPI endpoint `POST /api/analyze-pose` for a COCO-WholeBody (133-keypoint) MMPose model. Includes browser video duration/FPS repair.

**Deployment status:** Source repository only. Render server deployment and a successful model inference must be verified separately.

Use a Render Docker service with this repository's `Dockerfile`. See `README_KO.md` for Korean setup and cost warnings.
